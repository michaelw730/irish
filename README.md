# Irish

This repo is used to record notes and vocabulary from various learning resources of Irish Gaelic (Ulster Dialect) to aid learning.

The index.md file records some notes per chapter while the vocab.csv file is the main store of vocabulary.  This vocabulary file is made of words and phrases with meanings with some phrases being templates to increase the number of different sentences to practice.  The python script convert.py convets the vocab.csv file to vocab.md to produce a web viewable document of the vocabulary.
